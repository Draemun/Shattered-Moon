# GENERAL COMBAT RULES

| Rule | Details |
|---|---|
| Turn Structure | One full comment cycle between all battlers = 1 turn |
| Action Economy | 1 reactive action + 1 offensive action per turn |
| Item Use | Consumes your turn |
| Link Box | Allows 2 moves in one turn |
| Switch Out Moves | Do not consume your turn |
| Complexity Limit | No multi-complex actions, keep it reasonable |

# MOVE MECHANICS

| Mechanic | Details |
|---|---|
| Power Points (PP) | Start with standard PP; track however you prefer |
| PP Boosters | Use PP Up / PP Max to increase pools |
| Linked Moves | Consume PP from both moves |
| Status Move Cooldowns | Standard: 3 turns. Extended: 5 turns (Aurora Veil, Reflect, Light Screen, Terrains) |
| Critical Hits | Only roll if move has increased crit chance (1d4) |
| Secondary Effects | All chance-based effects must be rolled for |

# STATUS CONDITIONS

| Type | Condition | Effect | Cure |
|---|---|---|---|
| Permanent | Burn | Reduces physical attack | Heal Bell, Aromatherapy, Full Heal, Berries |
| Permanent | Poison / Badly Poisoned | Ongoing damage | Same as above |
| Permanent | Paralysis | Reduced speed, chance of full paralysis | Same as above |
| Temporary | Confusion | 1/3 chance to end early; ends with accuracy boosts | Dice roll 1d3 |
| Temporary | Freeze | Ends when hit by Fire-type move | Dice roll 1d3 |
| Temporary | Sleep | Ends when hit by sound-based move | Dice roll 1d3 |
| Special | Starstruck | 1/3 chance move fails each turn | Permanent until cured |

*Destiny Knot Interaction: Reflects Starstruck back to inflictor if held*

# WEATHER & FIELD EFFECTS

| Type | Duration | Extension Method |
|---|---|---|
| Sun, Rain, Sandstorm, Hail, Snow | 5 turns | Weather Rocks (Heat, Damp, Smooth, Icy) |

# BANNED & ALTERED MECHANICS

### Completely Banned

- Legends: Arceus mechanics
- OHKO moves (Fissure, Horn Drill, etc.)
- Set damage moves (Seismic Toss, Night Shade, etc.)
- Endeavor
- Pain Split
- Destiny Bond
- Perish Song / Perish Body
- Cheese strategies / invincible builds

### Modified from Games

| Move/Mechanic | Change |
|---|---|
| Switch Out Moves | Create distance, reset stats, trigger abilities, no turn cost |
| Endure | Max 1 PP, survives one fatal hit |
| Fling | Item becomes a recallable weapon, 5 uses per RP, blocked by Knock Off/Embargo |
| Nature Power | RP-based, locks to one move, must match environment |
| Secret Power | RP-based secondary effect, locks after first use |

### Entry Hazards

| Hazard | Effect | Duration | Cooldown |
|---|---|---|---|
| Stealth Rock | Chip damage | 3 turns | 3 turns |
| Sticky Web | Halves Speed | 3 turns | 3 turns |

### Trapping Moves

| Move Type | Effect | Duration | Cooldown |
|---|---|---|---|
| Fire Spin, Whirlpool, Bind, Wrap, etc. | Traps target | 3 turns | 3 turns |

*Escape orbs DO NOT work against traps*

### Trapping Abilities

| Ability | Effect | Duration | Cooldown |
|---|---|---|---|
| Shadow Tag, Arena Trap, Magnet Pull | Traps target | 3 turns | 3 turns |

### Special Trapping Moves

| Move | Effect | Notes |
|---|---|---|
| Octolock | Halves Defense & Sp. Defense | Standard trapping rules apply |
| No Retreat | Boosts all stats, prevents fleeing | Can only be used once per RP |

# ABILITY CHANGES

| Ability | Change |
|---|---|
| Libero / Protean | Type changes with each move used (no limit) |
| Gale Wings | Restored to full power; priority on all Flying-type moves |
| Vivid Aura (replaces Cute Charm) | Contact hit = 1/3 chance attacker becomes Starstruck |
| Starstruck Effect (Removes Infatuation) | Afflicted Pokémon's moves have 1/3 chance to fail. |

# THE DM CLAUSE

Staff may bend rules for story purposes, but that depends case by case.

**If there's any unlisted mechanic, assume it works as it would in canon Pokémon.**

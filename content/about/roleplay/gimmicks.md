# BATTLE GIMMICKS GUIDE

### UNIVERSAL RULES

- **One Gimmick Per RP**
- No combining gimmicks in the same battle
- If you have multiple, declare which one you are going to use

# MEGA EVOLUTION

| Details | Information |
|---|---|
| How to Obtain | Server events, special rewards, rank reward |
| Activation | Possess correct Mega Stone |
| Buffs | +100 for every stat |
| Frequency | Once per RP |

*There's no X/Y/Z megastones. The characters are free to swap between those forms. Communicate before any CRP what form has been chosen.*

# LAQUIUM

Laquium copies the sheer power of Ferox energy. Item slot.

| Details | Information |
|---|---|
| Type | Pokémon-made synthetic item, replicates Ferox energy without natural exposure |
| Stat Boost | Raises stats to the max of your tier for the duration |
| Duration | 3 turns active, 2 turns cooldown, repeatable |
| Splinter Combat | No weapons required to attack Soul Splinters while active |
| Cost | 350 (intentionally cheap to normalize market saturation) |
| Withdrawal | Must be noted in sheet. Lasts 2 RPs |

During the active phase the character does not feel injuries. The wounds only register when the cooldown hits, at which point the pain is severe. This creates a dangerous incentive to push straight into the next cycle.

### Targeting Roll (d6 at start of each active turn)

| Turn | Ally Hit Range |
|---|---|
| Turn 1 | 1 hits allies, rest is safe |
| Turn 2 | 1-2 hits allies, rest is safe |
| Turn 3 | 1-3 hits allies, rest is safe |

*Use a second dice to determine which ally is struck on a hit. Counter resets at the start of each new active phase.*

# FEROX

Ferox is a natural phenomenon caused by the Void. The Pokémon does not choose this state. The gimmick crystallizes only after they are defeated, manifesting as a physical item.

| Details | Information |
|---|---|
| Trigger | Naturally triggered by excessive Infinity Energy or Void Echoes exposure |
| Eligible Forms | Mega Ferox, Dynamax/Gigantamax Ferox, Tera Ferox (Z-Moves do not qualify) |
| Stat Boost | Stats raised to maximum ceiling (3,000-4,000 or 5,000) |
| End Condition | Mission ends only when the Pokémon is knocked out (mandatory) |
| Difficulty | ??? rated. Ferox tag required on battle |
| Min Stats | 800 required to participate |
| Approval | All proposals must go through ModMail |

Risk of maiming and death is significantly elevated.

At the start of each turn, roll a dice to determine targeting. Each character is assigned a number.

# GIMMICK INTERACTIONS

- Z-Move beats Mega
- Mega beats Tera
- Tera beats Dynamax
- Dynamax beats Z-Move
- Rakuium can work together with any gimmick in the item slot.

**DO NOT ABUSE THEM.**

# PROGRESSION SYSTEM

Every completed roleplay earns your character Stats and Credits:

- **Stats** increase your character's BST (Base Stat Total), representing their overall power level
- **Credits** function as the in-universe currency for the server economy

### How to Claim Rewards

- Add the earned stats and credits to your character profile
- Post in "character updates" with:
  - Link to the completed RP
  - Character name
  - Mathematical breakdown of rewards earned

**Only claim rewards after the RP is fully completed**

# REWARD STRUCTURE

| Activity Type | Stats + Credits |
|---|---|
| Casual RP | 10 + 100 |
| Combat RP | 30 + 300 |
| Team RP | 50 + 500 |
| Group RP (3+ different people) | 60 + 600 |
| Solo Storypost | 70 + 700 |
| Collaborative Storypost | 90 + 900 |
| Mission (Depends on difficulty) | 100-150 + 1,000-1,500 |
| Story Arc | 300 + 3,000 |

*Boosters such as Lucky Eggs (stats) and Amulet Coins (credits) may be applied to any activity up to and including Collaborative Storyposts.*

*Boosters cannot be used on Missions, Story Arcs, or Special Events.*

# MAXIMUM STAT LIMITS

Character progression is capped based on character type:

| Character Type | BST Cap |
|---|---|
| Normal Pokémon / Mythical Pokémon / Noteworthy Character / Lesser Soul | 3,000 BST |
| Higher Soul / Echelon / Commander | 4,000 BST |
| Legendary Pokémon | 5,000 BST |
